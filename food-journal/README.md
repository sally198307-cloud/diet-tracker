# 日日好食 · 飲食手帳

本網站程式碼及其 GitHub 儲存庫為 **Public（公開）**。

## 重要資料安全說明

本網站可將飲食紀錄、照片、喝水與健康回報資料，在裝置端使用 AES-GCM（PBKDF2 衍生金鑰）加密，再保存為 `private-backups/journal.enc.json`。路徑沿用舊版以保留相容性，並不代表資料夾是私人可見。

**任何人都能取得公開儲存庫中的加密檔案，並永久保存副本。** 密碼過弱、外洩或未來加密實作出現漏洞時，所有舊資料可能被讀取。不要把未加密 JSON、原始照片、Token、密碼或任何個人資料直接提交到公開 GitHub。

## 功能

- 主食／蛋白質／蔬菜每日目標 3／3／4
- 新增餐點：自行輸入餐點名稱，記錄三項份量、餐次與多張照片
- 歷史餐點：自動帶入上次份量，允許本次修改
- 獨立喝水紀錄與每日十項回報
- 七日照片與紀錄直接輸出列印 PDF，無封面
- 瀏覽器 IndexedDB 保存、JSON 匯入／匯出
- 選用 GitHub 公開儲存庫的加密備份與還原

## 設定同步

1. 開啟 HTTPS 網址的手帳，進入「週報 → GitHub 公開儲存庫加密同步」。
2. 儲存庫輸入 `sally198307-cloud/diet-tracker`。
3. 在 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens，建立只對 `diet-tracker` 有 Contents: Read and write 權限的 Token。請設定有限有效期限，且不要分享 Token。
4. 在網頁自行輸入 Token 和**至少 16 字元的高強度、專用加密密碼**，確認公開儲存庫風險後連線。
5. 點「立即加密備份」。換裝置時重新連線後點「從 GitHub 還原」。
6. 記牢加密密碼，遺失即無法解密。請定期另外下載 JSON 並離線安全保存。

## 限制

- **目前只完成程式碼上傳，未代使用者建立 Token、登入或驗證第一次真實雲端備份。**
- 自動同步僅在網頁開啟且已連線時觸發；未連線時只有本機資料。
- 多裝置同時編輯可能產生同步衝突；系統偵測版本變化時會停止覆蓋，需人工確認。
- GitHub 不是適合大量照片長期保存的專用儲存服務。包含大量照片的加密檔會持續佔用儲存庫容量和歷史版本。
- GitHub Pages 是靜態網頁服務，不會單靠公開程式碼就自動保存個人資料；必須完成連線與備份設定。
